LKA Invoices

Source code guide: what each main file does
Lingeshwar Kaparthi & Associates · Code: github.com/adi-repo-ai/ca-invoice-app (branches main and staging) · Updated October 2026

How the pieces fit. The website (React, in src/) runs in the browser. Pages show screens and call the data layer (src/data/), which reads and writes Firestore directly; every write is checked by firestore.rules. Pure calculations (GST, money, numbering) live in src/lib/. PDFs are drawn in the browser by src/pdf/. The few actions a browser must not be trusted with (roles, deleting accounts, first admin, numbering reset) go through src/api.ts to the Netlify Functions in netlify/functions/, which use the secret Firebase admin key. Money is always whole paise (₹1 = 100) to avoid rounding errors.

1. App shell

FileWhat it does
src/main.tsxStarting point: mounts the app with the router and the sign-in provider.
src/App.tsxAll page addresses (routes) and the guards: signed-in only, admins only, revenue (owner) only. Shows the TEST SITE banner.
src/firebase.tsConnects to Firebase (sign-in + Firestore) using the VITE_FIREBASE_* values; switches to the local emulators in development.
src/auth.tsxWho is signed in, their role (ADMIN/STAFF) and permissions (revenue fin, payments pay) from the signed token; 30-minute idle sign-out; useActor() for audit entries.
src/api.tsCalls a Netlify Function with the user's sign-in token attached.
src/settings-context.tsxLoads firm settings once per visit and shares them with every page.
src/theme.tsLight / dark / follow-device theme, remembered per device.

4. Data layer (src/data/) — every database read and write

FileWhat it does
invoices.tsThe invoice engine: createDraft, updateDraft, issueInvoice (transaction: next number, today's date, firm snapshot), recordPayment, cancelInvoice, deleteInvoices; lists, counts, totals, overdue, search by number. Each change writes an audit entry in the same step.
clients.tsAdd / edit / delete clients; name-prefix search, newest list, tag filter (with a fallback while its index builds), count.
settings.tsLoad and save the firm settings document.
audit.tsAppend-only activity log: add entries, list recent / per invoice, describe them in words.
home.tsEach person's private tasks, events, notes and links.
sampleData.tsTest site only: creates 6 TEST clients and 10 invoices through the normal functions above.

report.ts, csv.ts, clientImport.tsReport numbers; safe CSV export; CSV client import.
siteEnv.tsisTestHost(): true only on Netlify test addresses (with "--"); drives the banner and sample-data card.
celebrate.ts, image.ts, defaultLogo.tsConfetti; logo resizing; default logo.

FileWhat it does

8. Security, configuration, scripts and tests

FileWhat it does
firestore.rulesThe real security. Who may read / write each collection; invoices numbered without gaps; issued invoices locked; payments need the payments permission; deletes admin-only; invites owner-only; audit log append-only.
firestore.indexes.jsonSearch / sort indexes (status + date, client + date, tags + name, …). Deployed from Cloud Shell.
netlify.toml, firebase.jsonBuild settings, security headers, page routing / which rules and indexes files Firebase deploys.
.env.example, package.jsonList of settings needed (no real values) / libraries and commands (npm run build, test:all, seed:test…).
scripts/create-admin (make an owner; --key file option), seed-emulator (local demo), seed-test-data (test project only; refuses live).
tests/emulator/, src/**/*.test.ts93 automated checks: security rules, server functions, numbering, GST, money, words, CSV, reports, test-site detection.
