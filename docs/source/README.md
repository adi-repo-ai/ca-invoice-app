# PDF guide sources

Each PDF in `docs/` is printed from the HTML file of the same name here.

To update a guide:

1. Edit the `.html` file (plain HTML; styles are at the top of each file).
2. Open it in Chrome → **Print** → Destination **Save as PDF**, Paper **A4**,
   Margins **Default**, and tick **Background graphics**.
3. Save it over the matching PDF in `docs/` (e.g. `LKA-Invoices-Environment-Setup.pdf`)
   and commit both files.
